# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x (v1) | ✅ Active |

## Reporting a Vulnerability

This is a personal open-source project. If you find a vulnerability, please open an issue on GitHub or contact me directly.

Please do not report vulnerabilities via public channels before they are assessed.

Issues: https://github.com/EversonRubira/ArqSync/issues
